### Code and Content

- Website is generated with [Astro framework](https://astro.build/). Astro is quite fantastic in its simplicity: it generates static files with plenty of convenience, but without much magic. I am quite happy to have migrated away from GraphQL-complexities of [Gatsby](https://www.gatsbyjs.com/).
- Code is [open-sourced on GitHub](https://github.com/lekevicius/lekevicius.com); note that the design is copyrighted and should not be used as a template for your own website.
- Content is managed from a self-hosted [Strapi](https://strapi.io/) instance.
- Hosted on [Netlify](https://www.netlify.com/). Strapi is configured to trigger a rebuild webhook any time content is published or updated.
- Media is hosted on [Hetzner's S3-compatible object storage](https://www.hetzner.com/storage/object-storage/).

### Design

- Typeset in Inter, the best "default" font.
- Background features a shader based on the one found on Stripe website.
- Designed in Figma. Not suprising in the slightest.
